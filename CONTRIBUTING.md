# Contributing

Thank you for helping improve Grow4Me Laravel Data Connector.

1. Fork the repository and create a focused branch.
2. Add or update Pest coverage for every behavior change.
3. Run `composer test` and `vendor/bin/pint`.
4. Keep adapters domain-specific; keep the package contract domain-neutral.
5. Never add credentials, tenant identifiers, or customer-specific defaults.

Bug reports should include Laravel/PHP versions, a minimal adapter, the expected
contract envelope, and sanitized logs.
